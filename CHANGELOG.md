# Changelog

## 1.1.0

First public release.

- Solid backdrop behind the UI in green, blue, magenta, black, white, grey or a custom colour.
- Menu and minimap button (LibDBIcon when another addon provides it).
- Visible UI modes: everything, minimap only, or one picked window.
- Screenshot button that hides the menu during the capture.
- Slash commands (`/gs`) and keybindings.
